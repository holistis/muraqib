# Code of Conduct

This is a small, solo-maintained project. The expectations are simple:

- Be respectful in issues, pull requests, and discussions. Disagreement about code is fine, personal attacks are not.
- No harassment, discrimination, or abusive language toward anyone.
- Assume good faith. Most bug reports and PRs come from people trying to help.

## Reporting

If something crosses a line, open an issue or email the address in the maintainer's GitHub profile. Reports are handled by the maintainer directly, there is no larger team behind this project.

## Scope

This applies to all spaces connected to this repository: issues, pull requests, discussions, and any commit history or documentation here.
